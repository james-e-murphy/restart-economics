# Exhibits

Empty until the `plan-frozen` tag. See README working rule 1: no result is committed before the
plan is frozen.

One notebook, `exhibits.ipynb`, regenerates every figure and table in the paper from the derived
tables. The main-text exhibits are the ones PLAN.md Section 7 names. They are:

- a table of policy value by configuration for steps i to iii-b;
- a figure of the state rule's margin over the best schedule;
- a figure of the best cross-configuration schedule against each configuration's own optimum.

The diagnostics sit beside the results they explain. Everything else is appendix material, reported
in full and not argued from.
